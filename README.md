Задание 1, 2. Настроить JWT (JSON Web Token, pip install djangorestframework-simplejwt) аутентификацию с использованием SimpleJWT и 
реализовать пермишены для защиты API. Убедитесь, что только авторизованные пользователи могут 
выполнять определённые действия:
+ Чтение данных (GET-запросы) было доступно всем (AllowAny).
+ Изменение данных (POST, PUT, DELETE) требовало аутентификации (IsAuthenticated).
+ Управление категориями (создание, обновление, удаление) было доступно только администраторам (IsAdminUser).
1) Для большинства представлений 
(TaskListCreateView, TaskDetailUpdateDeleteView, SubTaskListCreateView, SubTaskDetailUpdateDeleteView) 
используем IsAuthenticatedOrReadOnly, чтобы: GET-запросы были доступны всем.
POST, PUT, DELETE — только авторизованным пользователям.
2) Для get_subtasks_by_task_and_status и get_task_statistic используем AllowAny, 
так как это только GET-запросы, и они безопасны для публичного доступа.
3) Для CategoryViewSet используем кастомную логику: 
GET: AllowAny. POST, PUT, DELETE: IsAdminUser.
